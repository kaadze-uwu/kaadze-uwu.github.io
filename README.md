# MI LANDING PAGE
Aquí se realizará un proyecto sobre una landing page de mi propio negocio que he podido crear por mi propia cuenta.
Habrán elementos principales en la landing page como:
- Una cabecera con un menú y mi logo
- Un portfolio con varios trabajos que he hecho anteriormente
- Las herramientas que uso para hacer los sitios web
- Al hacer clic sobre cada apartado del menú, habrá una página para cada elemento. Por ejemplo, si se hace clic en "Sobre mí", habrá una página web con los elementos necesarios ahí dentro.
