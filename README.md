# MI LANDING PAGE
---
Aquí se realizará un proyecto sobre una landing page de mi propio negocio que he podido crear por mi propia cuenta.
Habrán elementos principales en la landing page como:
1. Una cabecera con un menú y mi logo
2. Un portfolio con los trabajos más recientes que he completado
3. Las herramientas que uso para hacer los sitios web
4. Al hacer clic sobre cada apartado del menú, habrá una página para cada elemento. Por ejemplo, si se hace clic en "Sobre mí", habrá una página web con sus elementos necesarios ahí dentro.
---
También habrán otros elementos, como los siguientes:
+ Dentro del apartado "Sobre mí", habrá una breve descripción sobre quién soy, mis estudios, trabajos realizados previamente, y cómo he llegado hasta aquí
+ Dentro del apartado "Contáctame", habrá un simple formulario en donde podrás rellenar tu información para poder contactarme
+ En la página principal, un botón que dice "CONTÁCTAME!" que llevará directamente a ponerte en contacto conmigo
+ Dentro de "Mis trabajos", habrá un portfolio más completo sobre todos los trabajos que he hecho
